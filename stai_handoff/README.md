# STAI handoff folder

Added from the planning conversation that preceded this project (17 November 2026).
Nothing in this folder is application code. It is source material for the build.

| Path | What it is |
|---|---|
| `PROJECT_BRIEF.md` | Owner decisions, proposals awaiting approval, assumptions and open items |
| `MASTER_PROMPT_v1.0.md` | The owner's specification, verbatim |
| `AUDIT_NOTES.md` | Verified findings on Freqtrade, TradingAgents, OKX, Replit hosting and the logo |
| `brand/stai_logo_dark_background.png` | Logo with white text, for the dark app |
| `brand/stai_logo_light_background.png` | Logo as supplied, for emails and printed reports |
| `smart_trader_analytics/` | Reusable analytics from Smart Trader with their tests. Its README lists the port steps. |
| `freqtrade_gate_probe/` | Strategy, example configuration and decision log from the approval gate test |

No file here contains credentials. The example Freqtrade configuration has empty exchange keys
and placeholder API-server values.
