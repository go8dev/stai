---
name: Task tool limits
description: Size limits and one-shot behaviour of the task and follow-up tools, learned by hitting them.
---

Follow-up task descriptions are limited to 4,000 characters each.

**Why:** a description of about 4,400 characters was rejected when the follow-ups for a phase were proposed. The rejection happens before anything is recorded, so the proposal, which can be made only once per assigned task, could still be sent again with shorter text.

**How to apply:** measure each description before sending and keep it under about 3,900 characters. Leave the steps list out first. What and why, done looks like, a short constraints list and the relevant files carry more for the agent that picks the work up, and the constraints list is where lessons from this project belong (ports, how a one-off check was built, ordering rules).
